# Nutanix User Group Norway 3. September 2026

Den 3. september samler vi igjen det norske Nutanix-miljøet – denne gangen hos Move i Oslo.



Vi får besøk av [**Simon Todd MSc**](https://www.linkedin.com/in/stastro/), som tar oss gjennom **Nutanix Enterprise AI** og hvordan plattformen utvikler seg fra å gjøre det enkelt å kjøre og konsumere GenAI-modeller til å bli et sentralt lag for enterprise AI.

Blant annet ser vi nærmere på AI Gateway – hvordan virksomheter kan få kontroll, sikkerhet og governance rundt bruken av ulike AI-modeller, med ett felles API for LLM-er enten de kjører lokalt eller som eksterne skytjenester som Anthropic.

Vi skal også innom **Nutanix Kubernetes Platform, siste nytt fra Nutanix** – og selvfølgelig blir det tid til **gode diskusjoner, pizza og quiz!**
